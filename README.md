# Telegram Bot

Бот на Go и [go-telegram/bot](https://github.com/go-telegram/bot).

## Быстрый старт
```bash
cp .env.example .env   # вписать BOT_TOKEN от @BotFather
make run
```

## Разработка с Claude Code
Проект настроен под плагин [superpowers](https://github.com/obra/superpowers):
при открытии папки Claude Code предложит доверить маркетплейс и установить плагин.
Свои агенты и скиллы лежат в `.claude/`, правила — в `CLAUDE.md`.
