# Передача проекта

Этот файл позволяет продолжить работу с другого аккаунта, на другой модели или в другом инструменте. История чатов не переносится, поэтому всё важное должно быть здесь. Обновляй файл в конце каждого значимого этапа.

## С чего начать

1. Прочитай [AGENTS.md](../AGENTS.md), особенно классификатор рисков.
2. Прочитай разделы «Состояние» и «Следующие шаги» ниже.
3. Проверь окружение: `go test -race ./...` и `bash .claude/hooks/guard-bash_test.sh` (нужен `jq`).

## Состояние (2026-10-30)

Есть только каркас, бизнес-логики нет.

- Работает: `/start`, `/help`, загрузка конфига, long polling, корректная остановка по SIGTERM. Покрыто тестами с фейковым `Sender`.
- Бот с настоящим токеном ещё ни разу не запускался, проверены только сборка и тесты.
- Пустые пакеты-заготовки: `internal/keyboards`, `internal/service`, `internal/state`.
- Плагин superpowers прописан в `.claude/settings.json`, но его установка и работа не проверялись.

## Принятые решения

| Решение | Почему |
|---|---|
| Go вместо Python | Выбор владельца проекта: ему так привычнее. Первая версия на aiogram была выброшена |
| `github.com/go-telegram/bot` | Без внешних зависимостей, обработчики на `context`, актуальный Bot API |
| Узкий интерфейс `Sender` вместо `*bot.Bot` | Хендлеры тестируются без сети |
| Конфиг через env и stdlib, логи через `slog` | Меньше зависимостей |
| Защита в двух слоях: правила и хук | Правила читает агент, хук останавливает команды независимо от него |

## Что нужно настроить на новом месте

- Клонировать `git@github.com:asfarrr/tdphelper.git`.
- Установить Go 1.27+, `golangci-lint`, `jq`.
- Создать `.env` по образцу `.env.example`. Его нет в git, токен берётся у @BotFather или у владельца.

## Переход на другой инструмент

Переносимая часть: `AGENTS.md`, этот файл, код и `Makefile`. Остальное привязано к Claude Code:

| Файл | В другом инструменте |
|---|---|
| `CLAUDE.md` | Не нужен, используй `AGENTS.md` |
| `.claude/agents/*.md` | Обычные описания ролей: подключи как системные промпты или читай перед задачей |
| `.claude/skills/*/SKILL.md` | Обычные инструкции: читай подходящую перед задачей |
| `.claude/settings.json` | Перенеси запреты в настройки разрешений нового инструмента |
| `.claude/hooks/guard-bash.sh` | Подключи как проверку перед запуском команд, см. ниже |
| Плагин superpowers | Если недоступен, следуй порядку из `AGENTS.md`: дизайн, план, сначала тест, проверка перед завершением |

**Без подключённого хука защита держится только на том, что агент соблюдает `AGENTS.md`.** Подключи проверку в первую очередь. Скрипту не нужен Claude Code, он получает JSON в stdin:

```bash
jq -n --arg c "git status" '{tool_input: {command: $c}}' | .claude/hooks/guard-bash.sh
```

- Код выхода 2: команда запрещена, причина в stderr.
- Код 0 и JSON в stdout с `permissionDecision: "ask"`: нужно подтверждение пользователя.
- Код 0 без вывода: можно выполнять.

Хук ищет опасные команды по регулярным выражениям и не заменяет песочницу. Запутанную команду он может пропустить, а на обычный текст в команде иногда срабатывает ошибочно.
