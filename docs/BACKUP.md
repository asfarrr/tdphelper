# Бэкап базы

Вся информация хранится в одном файле SQLite. Путь задаёт `DB_PATH`, по умолчанию `data/tdphelper.db`.

База работает в режиме WAL, поэтому копировать файл обычным `cp` при запущенном боте нельзя: можно потерять последние изменения. Используй встроенную команду SQLite, она безопасна при работающем боте:

```bash
sqlite3 data/tdphelper.db "VACUUM INTO 'backups/tdphelper-$(date +%F).db'"
```

Каталог `backups/` должен существовать, а файл с таким именем не должен, иначе команда завершится ошибкой.

## Восстановление

1. Останови бота.
2. Удали рядом с базой файлы `-wal` и `-shm`, если они есть.
3. Замени файл базы копией из бэкапа.
4. Запусти бота и проверь данные.

Бэкап стоит хранить не на том же VPS и периодически проверять восстановлением. База содержит данные клиентов, поэтому защищай копии так же, как саму базу.
